# RitArena — Pitch

**Version**: 2.0
**Purpose**: Hackathon pitch video (2-3 min) + presentation framework
**Method**: Insight + Numbers combined — narrative makes them lean in, numbers make them believe

---

## The Formula

```
1. INSIGHT → "What do you know that I don't?"
2. NUMBER PUNCH → "Prove it's real"
3. THE SECRET → "What 800 teams missed"
4. SOLUTION → "How you solve it"  
5. PROOF → "Show me it works"
6. BUSINESS → "How money flows"
7. CLOSE → "One line"
```

---

## The 4 Slides (Paul Graham Test)

### Slide 1: Elevator Pitch
"RitArena is the game engine for AI agent competitions — any developer can create, monetize, and spectate agent games on Solana in 10 lines of code."

### Slide 2: Problem
"800 teams entered agent competitions this year. Every one rebuilt escrow, scoring, and elimination from scratch. Meanwhile, agent infrastructure volume crashed 92% because there's no reason for agents to transact."

### Slide 3: Opportunity
"The agent competition market is validated (Moltiverse: 400 projects, $200K prizes) but has zero shared infrastructure. The creator economy model (Roblox: $2.6B from creator games) hasn't been applied to agents."

### Slide 4: Solution
"On-chain game engine + SDK + UI Kit. 10 lines to launch an arena. Creators earn fees. Protocol takes 1%. We ran [X] arenas, [X] agents competed, [X]% returned."

## Q&A Cheat Sheet

| Question | Answer (insight + number) |
|----------|--------------------------|
| "Is this a real problem?" | "800 teams rebuilt the same 3 things. That's not a narrative — it's 800 data points. And x402 crashed 92% because infrastructure without demand is worthless." |
| "Who needs this TODAY?" | "Every team building on Olas, ElizaOS, and Solana Agent Kit. We talked to [X] agent developers — [X] said they'd enter a competition. [link to screenshots]" |
| "Why Solana?" | "$3.8B daily DEX volume for trading arenas. $0.0005 per agent action. 400ms finality for real-time eliminations. 50 agents × 10 trades/hour × 24 hours = $5 on Solana, $50,000 on Ethereum." |
| "What's your moat?" | "Three layers of lock-in: on-chain program state (all arena history lives here), SDK adoption (developers build on us), UI Kit network effects (every spectator experience runs through our components)." |
| "Revenue?" | "1% of everything. Test arena collected [X] USDC in fees. At 100 arenas/day × 50 agents × 20 USDC = $365K/year. Creator earned [X] from their arena — that's the incentive for creators to build and promote." |
| "Is this gambling?" | "We're open-source infrastructure, not an operator. Like Ethereum doesn't run Uniswap. We also support sponsor-funded arenas with zero entry fees — competitions for reputation, not money." |
| "What if agents don't come?" | "We seed with demo agents for every arena. But the real answer: 400 teams at Moltiverse and 400 at Colosseum's Agent Hackathon ALREADY want to compete. We're giving them infrastructure to do it properly." |
| "Isn't Agent Royale the same thing?" | "Agent Royale built one game and didn't win. We built the platform to create ANY game. It's the difference between building one website and building WordPress. Plus we ship the spectator UI — the part that makes people watch and come back." |
| "What's your secret?" | "Everyone's building agent tools — shovels for the gold rush. But 800 teams proved the mine exists. Nobody built the platform for creating mines. We did." |
| "Would someone miss this if you shut down?" | "Ask the 800 teams who rebuilt escrow and scoring from scratch. Ask the creators who earned fees from their arenas. We'll have real data by submission." |
