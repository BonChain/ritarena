Complete reference for `@ritarena/sdk` v0.3.3.

## Class hierarchy

```
RitArenaReader        ← read-only queries + subscriptions
  └── RitArena        ← adds write methods (needs wallet)

GameServer            ← oracle automation (extends EventEmitter)
```
